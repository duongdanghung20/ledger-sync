# Ledger-Sync — self-hosted expense-to-ledger tool

- End-to-end tech-stack: **Next.js + FastAPI + PostgreSQL**. 
- Imports CSV bank exports, categorizes transactions, and exports a clean **double-entry journal** to QuickBooks Online.
- Full-stack mono-repository across frontend, API, data model, and deployment (Github CI/CD + Docker + Docker Compose).
